# traffic-video-analytics 문서 인덱스

> 최종 갱신: 2026-11-03
> 드론·CCTV 교통 영상에서 차선 위반(실선 침범)·오토바이 위반(다인승·헬멧 미착용)을
> 판정하고 해당 차량의 번호판을 읽는 응용.

문서는 **주제별 폴더**로 나눈다(2026-11-03, 기존 스테이지 축 `01-lane-postprocess/
02-model-selection/04-lane-learning/05-rider-safety`에서 재편 — `04-lane-learning`

새 문서를 만들 때 아래 기준으로 배치할 것. `scripts/`, `output/`도 같은 번호를 쓴다
(`03`, `06`은 생성물/코드가 없는 문서 전용 주제라 거기서는 번호가 비어 있다).

**2026-11-03 파일명 한글화**: 각 폴더 안 문서 파일명을 영문 대문자(`LANE_LEARN_05_
RATIO_CROSSING_TRIGGER.md` 같은 것)에서 `"N. 한글제목.md"` 형식으로 전부 바꾸고,
폴더별로 번호를 1부터 끊김 없이 다시 매겼다(워크스페이스 공통 규칙 그대로). 앞으로
docs 문서는 한글 파일명을 기본으로 쓴다 — 코드 파일(`scripts/*.py`, `*.sh`)만 위험
요소(경로·import·셔뱅)가 있어 영문을 유지한다.
