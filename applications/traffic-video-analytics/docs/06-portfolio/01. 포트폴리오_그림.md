## 1. IoU vs IoA 비교 — 왜 IoA(포함비)를 채택했나

`test/output/ioa_vs_iou/ioa_vs_iou.png` (1513×900) · `_half.png` (절반)
스크립트: `scripts/04-오토바이다인승/ioa_vs_iou_slide.py`

### 무엇을 보여주나

오토바이 다인승 판정에서 사람↔오토바이 **연관**에 IoU 대신 IoA를 쓰는 근거
(`01. 다인승_후처리.md` §2.1). 왼쪽은 실제 드론 프레임
(`recard_visible_164259` 클립 frame 90, `det-best.pt` 검출), 오른쪽 패널에 수치.

| | 실측값 |
|---|---|
| 사람 박스 면적 | 5,165 |
| 오토바이 박스 면적 | 15,529 (사람의 **3.0배**) |
| 교집합 면적 | 4,303 |
| **IoU** = 교집합/합집합 = 4,303 / 16,391 | **0.26** ✗ 임계 0.30 미달 → 탑승자 놓침 |
| **IoA** = 교집합/사람박스 = 4,303 / 5,165 | **0.83** ✓ 임계 0.30 초과 → 탑승자로 연관 |

드론 하향 뷰에서 오토바이 박스가 사람 박스보다 훨씬 커서, 사람이 확실히 얹혀 있어도
합집합이 커져 IoU가 낮게 나온다. 사람 박스 기준 포함비(IoA)로 연관해야 놓치지 않는다.

> 요청은 "IoU 0.26 / IoA 0.84" 였으나 실제 검출값은 **0.26 / 0.83**. 스캔한 300여
> 프레임에서 IoA가 정확히 0.84인 쌍은 없었고 0.83~0.86 범위. 포트폴리오는 실측값 사용.

### 재생성

```bash
PYTHONNOUSERSITE=1 CUDA_VISIBLE_DEVICES=5 \
  /home/hsjeong/miniconda3/envs/Yolov26_env/bin/python \
  /home/hsjeong/workspace/applications/traffic-video-analytics/scripts/04-오토바이다인승/ioa_vs_iou_slide.py \
  --video /home/hsjeong/workspace/dataset/etc./test_video/drone/clip_164259_f6025_1500.mp4 \
  --frame 90 --pick best \
  --out /home/hsjeong/workspace/applications/traffic-video-analytics/test/output/ioa_vs_iou/ioa_vs_iou.png
```
`--pick best`(목표 수치 근접 쌍) / `rear`(2인 탑승 뒷사람) / `front`, `--frame N`, `--title`/`--subtitle`.

## 2. 프로젝트 타이틀 슬라이드 — Before / After

`test/output/title_beforeafter/before_after.png` (배지 있음) ·
`before_after_nobadge.png` (배지 없음, 슬라이드에서 직접 캡션)
스크립트: `scripts/04-오토바이다인승/title_before_after.py`

### 규격

**1704 × 1365 px = 14.43 cm × 11.56 cm @ 300 DPI.** PPT에 그대로 삽입.

| 패널 | 내용 |
|---|---|
| 위 (Before) | 하노이 교차로 드론 프레임 (`recard_visible_164259` 원본 f2900~3120 중 위반 최다 프레임 자동선택). 오토바이 무리 + 승용차·밴 + 차선·횡단금지 노면표시 |
| 아래 (After) | `det-best.pt` 검출 → 차량(하늘색)/오토바이(파랑)/사람(노랑) 박스 + bytetrack 트랙 ID(M11, C5, P41…, 표시용 1..N 재부여) + IoA 연관으로 2인 탑승 판정된 오토바이 = 빨강 "VIOLATION 2-up" |

같은 크롭 구간(원본 x400–2450 / y440–1300)을 위아래로 붙임.

### 준비 + 재생성

`.ts` 원본은 seek 시 회색 프레임 → 구간을 png로 먼저 추출:
```bash
ffmpeg -y -i /home/hsjeong/workspace/dataset/etc./test_video/drone/recard_visible_164259.ts \
  -vf "select=between(n\,2900\,3120)" -vsync 0 -an \
  /home/hsjeong/workspace/applications/traffic-video-analytics/test/output/title_beforeafter/seg_%04d.png
```
```bash
PYTHONNOUSERSITE=1 CUDA_VISIBLE_DEVICES=5 \
  /home/hsjeong/miniconda3/envs/Yolov26_env/bin/python \
  /home/hsjeong/workspace/applications/traffic-video-analytics/scripts/04-오토바이다인승/title_before_after.py \
  --frames-dir /home/hsjeong/workspace/applications/traffic-video-analytics/test/output/title_beforeafter \
  --pick 0 --conf 0.30 --crop 400,440,2450,1300 \
  --out /home/hsjeong/workspace/applications/traffic-video-analytics/test/output/title_beforeafter/before_after.png
```
`--pick 0`(위반 최다 프레임 자동) / `--pick N`(N번째), `--crop x0,y0,x1,y1`, `--no-badge`,
`--cm-w`/`--cm-h`/`--dpi`.

> seg_*.png 는 약 2GB — 생성 후 삭제함. 재생성하려면 위 ffmpeg 부터 다시.

### 아쉬운 점

아래 패널 밀집 구간(오토바이 무리)에서 라벨이 일부 겹친다. 더 여유 있는 다른 구간
(오토바이가 흩어져 달리는 프레임)이나 크롭을 원하면 `--pick`/`--crop` 조정.
