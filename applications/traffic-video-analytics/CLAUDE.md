# traffic-video-analytics 프로젝트 지침

## scripts/README.md 동기화 (필수)

`scripts/` 안의 파일을 **추가·이동·역할변경·폐기(archive행)** 할 때는
`scripts/README.md`도 같은 작업 안에서 같이 갱신한다. 이 README에는
"지금 실제로 쓰는 진입점 스크립트"만 적는다 — 실험용/구버전/헬퍼는 적지 않는다
(그런 건 `scripts/99-archive/`로 옮기거나 그냥 폴더 안에 둬도 되지만, README에는
절대 넣지 않는다).

**원칙**: README에 없는 스크립트는 지금 쓸 일 없는 코드로 간주한다. 사용자가
"이거 어떻게 실행해?"라고 물을 때 매번 코드를 뒤져서 답하지 않고, 이 README
하나로 바로 답할 수 있어야 한다.

갱신 시 각 항목에 포함할 것:
- 스크립트 경로
- 한 줄 용도 (비슷한 스크립트가 여러 개면 뭐가 다른지 명시)
- 복붙 가능한 전체 실행 명령어
