# GANet Feature 분석

GANet(`drone-ganet-res34-2cls-v1`, 후처리 cluster_by_center_thr=5)의 FPN 특징맵을 단계별로 보고,
BEV(위에서 내려다본 시점) 변환을 **학습 없이 추론에만** 넣었을 때 결과가 어떻게 바뀌는지 시험한 그림.

- 프레임: `1` = AIhub 부산 다리, `2` = 베트남 드론 001392, `3` = 0816 영상 f990(33초)
- 파일명: `{프레임}-{그림번호}. 이름.png`
- 스크립트는 `GANet/scripts/03-vis/`에 있음. GANet 소스는 수정하지 않고 forward hook으로만 바꿔 끼움.

## 기존 GANet 경로

```text
C3(1/8) ─────────────────────────────┐
C4(1/16) ───────────────┐            │
C5(1/32) → attention → AC5 → +C4 → +C3 → P3 → head(conf, offset)
```

## 그림별 테스트 과정

| 번호 | 내용 | 경로 | 스크립트 |
|---|---|---|---|
| 1 | FPN 단계별 히트맵 (활성 크기, 실선/점선 conf 기여도) | 기존 그대로, 7단계 C3·C4·C5·AC5·P4·P3(DCN 전)·P3 | `ganet_fpn_stage_heatmap.py` |
| 2 | BEV 특징맵 비교 (그림만, 추론에 안 넣음) | C3·C4·C5·AC5 vs BC3·BC4·BC5·BAC5 | `ganet_bev_feature_view.py` |
| 3 | BEV attention, 좁은 범위 | C5 → BEV로 펴기(BC5, 차선 사이 범위) → attention(BAC5) → **원본 시점으로 되돌리기** → +C4 → +C3 → head | `ganet_bev_sa_inference.py` |
| 4 | BEV attention, 도로 전체 범위 | 3과 같고 BEV 범위만 도로 전체(키포인트 98% 이상 들어가게) | `ganet_bev_sa_inference_cover.py` |
| 5 | cross-attention | attention의 Q = 원본 C5, K·V = BEV로 편 BC5 → AC5(원본 시점, 되돌리기 없음) → +C4 → +C3 → head | `ganet_bev_cross_attention.py` |
| 6 | 전체 BEV 경로 | C3·C4·C5를 모두 BEV로 펴기 → BC5에 attention(BAC5) → BAC5+BC4 → +BC3 → **head 직전에 한 번만** 원본 시점으로 되돌리기 → head | `ganet_bev_full_path.py` |
| 7 | 두 경로 합치기 | [AC5 → +C4 → +C3] 출력과 [6의 전체 BEV 경로 출력(되돌린 것)]을 head 직전에 합침. 줄별로 ① 더하기 ② 평균(½씩) ③ conf 쪽만 더하기(offset 쪽은 기존) | `ganet_bev_dual_fuse.py` |
| 8 | 두 경로를 학습 가중치 없이 합치기 (concat 뒤 새 층 대신) | P=7의 기존 경로, B=6의 전체 BEV 경로. conf 쪽만 합치고 offset 쪽은 기존. 줄별로 ① 칸별 max(P, B) ② conf 기준 선택(두 경로 conf로 softmax 가중) ③ 가중치 없는 cross-attention P + attn(Q=P, K·V=B) ④ 출력 conf 맵끼리 칸별 max | `ganet_bev_dual_paramfree.py` |
| 9 | BEV 이미지 입력 시 **경로별 검출 결과** (사다리꼴은 검출 없이 고정 비율: 윗변 y=0.45H 가운데 40% 폭, 아랫변 화면 전체 폭) | 이미지 → BEV 이미지 → backbone → BC3·BC4·BC5 → attention(BAC5). 줄별로 a: BAC5를 되돌려 +C4 → +C3(원본 이미지 것) b: BAC5 → +BC4 → +BC3 후 되돌림 b': b의 conf + 기존 offset | `ganet_bev_image_input.py` |
| 9 (프레임 공통) | `9. 경로별_과정도_BEV이미지입력.png`: 9번 그림 줄별(기존·a·b·b′) 계산 경로도. 파랑 = 원본 이미지 경로, 주황 = BEV 이미지 경로, 보라 = 되돌리기, 회색 점선 = 사다리꼴 밖 위치만 채우는 값 | - | `ganet_bev_image_path_diagram.py` |
| 10 | BEV 이미지 입력 시 **FPN 단계별 히트맵 결과** (1번 그림의 BEV 이미지 버전) | 이미지 → BEV 이미지(9와 같은 고정 비율 사다리꼴) → 모델 전체(backbone → C3·C4·C5 → attention → P4 → P3 → head). 배경·기여도 모두 BEV 이미지 기준, 되돌리기 없음 | `ganet_fpn_stage_heatmap_bev.py` |
| 11 | 차선 후보점 conf (0.4 기준) | 기존 모델 그대로. GANet과 같은 NMS(가로 3칸 최댓값)로 뽑은 점 중 conf 0.1 이상을 실선·점선 칸별로 표시. 노랑 = 0.4 초과(실제 키포인트), 빨강 = 0.1~0.4(탈락, 값 표기) | `ganet_candidate_conf_points.py` |
| 12 | 차선 후보점 conf (0.4 기준), **BEV 이미지 입력** (11번 그림의 BEV 이미지 버전) | 이미지 → BEV 이미지(9·10과 같은 고정 비율 사다리꼴) → backbone → BC3·BC4·BC5 → attention(BAC5) → +BC4 → +BC3 → head. 점·배경 모두 BEV 이미지 기준, 되돌리기 없음 | `ganet_candidate_conf_points_bev.py` |

공통 사항 (3~9):

- BEV 변환은 1차 추론(기존)에서 검출한 가장 왼쪽·오른쪽 차선 두 줄로 프레임마다 정합니다(9만 고정 비율).
- 되돌렸을 때 BEV 화면 밖이라 값이 없는 칸은 기존 값으로 채웁니다.
- 그림 구성: 윗줄 = 기존, 그 아래 줄 = 시험한 방식(7·8·9는 방식마다 한 줄, 9는 맨 왼쪽에 입력/BEV 이미지 칸 추가). 칸은 왼쪽부터 실선 conf, 점선 conf, 최종 검출입니다.
- 4·6·7·8·9 아래 줄의 하늘색 점선은 BEV로 펴는 사다리꼴 범위입니다.
