# 16. 전체 실험 성능 정리 (2026-11-13 기준)

> **결론**
> - 지금까지 가장 좋은 구조는 **P3del−SA (008)**: ep100~150 평균 F1 **.774** (최고 .780), 10.42ms.
>   현재 채택 모델(기존 res34, 004 ep130) 대비 평균 +0.033, 속도 −27%.
> - C5 뒤 attention을 **개선**한 시도(DA 009·010, APT 011~013)는 모두 **빼는 것(008)**을 넘지 못했다.
> - 모든 수치는 **1회 학습**이다. 같은 학습 안에서도 epoch마다 ±0.01~0.02 흔들려서, 0.01 이하 차이는 순위를 확정할 수 없다.

## 평가 방법

- 데이터: si_vietnam_drone val **163장** (GT 차선 1030개), 입력 1280×736.
- 지표: 예측 차선과 GT 차선을 위치로 매칭한 **precision / recall / F1**, 매칭된 선의 평균 거리(px).
  **위치만 평가**하고 실선/점선 클래스가 맞는지는 따지지 않는다(문서 8 4절). 스크립트 `scripts/04-eval/score_checkpoint.py`.
- epoch 10, 20, …, 150 체크포인트 15개를 모두 평가.
  - **최고 F1**: 15개 중 최고 (그 epoch의 P / R / 오차 함께).
  - **ep100~150 평균**: 학습이 수렴한 뒤 6개 체크포인트의 평균과 범위. 운 좋은 epoch 하나에 덜 휘둘리는 비교 기준.
- params·속도: V100 1장, 입력 1장, backbone+neck+head forward(후처리 제외), 100회×5번 중 최소. 11개 모두 같은 스크립트로 같은 날 측정.

## 2. 변경 하나씩의 효과 (ep100~150 평균 기준)

| 바꾼 것 | 비교 | 변화 | 판단 |
|---|---|---|---|
| **P3 제거** | 004 → 006 (res34) | +0.016 | 효과 있음, 속도 −24% |
| 〃 | 003 → 005 (res18) | +0.033 | 효과 있음, res18도 같은 방향 |
| 〃 | 007 → 008 (SA 없는 상태) | +0.022 | SA 유무와 상관없이 같은 방향 |
| **SA 제거** | 004 → 007 (P3 있음) | +0.010 | 범위 겹침 (.745~.749) |
| 〃 | 006 → 008 (P3 없음) | +0.016 | 범위 안 겹침 |
| SA → DA (query) | 006 → 009 | +0.005 | 흔들림 범위 |
| SA → DA (add) | 006 → 010 | −0.004 | 흔들림 범위 |
| DA 위치 인코딩 query vs add | 010 → 009 | +0.009 | 논문 방식(query)이 약간 높음 |
| APT 추가 (SA) | 006 → 011 | +0.011 | 일부 겹침 |
| APT 추가 (DA) | 009 → 012 | −0.001 | 차이 없음 |
| APT 추가 (SA 없음) | 008 → 013 | −0.009 | 손해 (008 최저 .769 > 013 평균) |
| 백본 res18 → res34 (P3del) | 005 → 006 | −0.005 | 차이 없음, res18이 3.8ms 빠름 |

> **초급자 설명:** 효과가 분명한 건 두 가지뿐입니다 — **P3를 빼는 것**과 **C5 뒤 SA를 빼는 것**. 둘 다 "덜어내는" 변경이고 속도도 빨라집니다.
> SA를 더 좋은 attention(DA)으로 바꾸거나 토큰을 줄이는(APT) "더하는" 변경은 모두 SA를 그냥 빼는 것만 못했습니다.
