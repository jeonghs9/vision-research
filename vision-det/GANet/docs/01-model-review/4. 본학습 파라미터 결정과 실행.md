# 본학습 파라미터 결정과 실행

> 2026-09-30. 관련: [3. 데이터 변환과 학습 스모크 테스트](3.%20데이터%20변환과%20학습%20스모크%20테스트.md)
>
> **결론: 입력 해상도 1280x736, batch_size=16(메모리 실측), lr=5e-4, 150epoch,
> 단일 GPU로 res18/res34 두 백본을 병렬 학습하기로 사용자와 같이 정했다.
> (처음에 혼자 제안+실행까지 해버려서 사용자가 "파라미터는 같이 정하기로
> 한 거 아니었나" 지적 — 학습을 멈추고 처음부터 다시 논의해서 정함.)**

## 1. 처음엔 혼자 정해서 실행함 — 사용자 지적으로 재논의

첫 시도는 입력 960x544/batch=8/lr=5e-4를 스스로 제안하고 바로 실행까지
했는데, 사용자가 "파라미터(입력사이즈, gpu, batch)는 같이 정하기로 한 거
아니었나?"라고 지적. 학습을 멈추고 체크포인트·로그를 지운 뒤 처음부터 다시
논의했다.

## 2. 입력 해상도 — 1280x736 (원본 대비 3배 축소)

원본 3840x2160(16:9). GANet FPN이 stride 8/16/32를 쓰므로 **32의 배수**여야
한다. 후보 3개를 제시:

| 후보 | 축소율 | 픽셀 수(960x544 대비) |
|---|---:|---:|
| 960x544 | 4.0배 | 1.0배 (가장 빠름, 점선이 뭉개질 위험) |
| **1280x736 (선택)** | 3.0배 | 1.8배 |
| 1600x896 | 2.4배 | 2.7배 (가장 느림) |

**CULane처럼 하늘을 크롭하지 않고 전체 프레임을 그대로 쓴다** — 드론 영상은
하늘 비중이 다르고 각도도 달라서 원본 비율(16:9)을 유지하는 쪽을 택했다.

## 3. batch_size — 메모리 실측 후 16으로 결정

“메모리 한계까지 실측해서 결정”을 사용자가 직접 선택. 1280x736 기준으로 실제
학습을 짧게 여러 번 돌려서 확인(처음엔 25초 타임아웃으로 재봤는데 큰
batch는 모델 로딩만으로 타임아웃 — 60초로 늘려서 재측정):

| batch_size | 결과 |
|---:|---|
| 16 | 성공, 8.8GB (V100 16GB 중 여유 많음) |
| 32 | 성공하지만 16080/16384MiB — 카드 거의 꽉 참 |
| 48, 64, 96 | OOM |

32는 기술적으론 되지만 150epoch 도는 동안 메모리 파편화 등으로 중간에 죽을
위험이 있어 **여유 있게 16으로 결정.**

## 4. GPU — 단일 GPU

“431장짜리 데이터에서는 병목이 GPU 연산량이 아니라 데이터 로딩/증강일 가능성이
높다”는 이유로 단일 GPU를 사용자가 선택. 멀티 GPU가 요구하는 SyncBatchNorm·DDP
복잡도(문서 3에서 이미 한 번 걸렸던 부분)도 피할 수 있어 여러모로 유리.

## 5. res18/res34 병렬 학습으로 확장

사용자가 "res18 말고 다른 백본도 되나" 질문 → ResNet34가 ResNet18과 채널
구조가 완전히 같아서(둘 다 BasicBlock, 64/128/256/512 채널) `model` 딕셔너리만
다시 정의하면 드롭인 교체가 된다고 설명 → 다른 GPU에서 병렬로 같이 돌리기로
결정. `res34_s8_full.py`는 `res18_s8_full.py`를 `import *`로 상속하고 `model`만
새로 정의(백본 depth=34, checkpoint=resnet34)하는 방식으로 작성.

(ResNet101은 Bottleneck 구조라 채널 수·FPN 레벨 수가 다르고 config를 많이
새로 짜야 해서 이번엔 시도 안 함 — 필요하면 나중에.)

## 6. 실험 폴더 이름 재정렬 — 01번부터

처음엔 `002-`(YOLinO 등 다른 프로젝트처럼 숫자를 이어가려던 습관)로 시작했는데,
사용자가 GANet 프로젝트는 01번부터 새로 시작하자고 정리. 최종:
- `test/001-res18-1cls-1280-150ep/`
- `test/002-res34-1cls-1280-150ep/`

## 7. 실행 명령어

```bash
# res18 (GPU1)
PYTHONNOUSERSITE=1 CUDA_VISIBLE_DEVICES=1 \
  /home/hsjeong/miniconda3/envs/ganet_cu101/bin/python tools/train.py \
  projects/cfgs/drone/res18_s8_full.py \
  --work-dir /home/hsjeong/workspace/vision-det/GANet/test/001-res18-1cls-1280-150ep \
  --no-validate --gpu-id 0

# res34 (GPU2)
PYTHONNOUSERSITE=1 CUDA_VISIBLE_DEVICES=2 \
  /home/hsjeong/miniconda3/envs/ganet_cu101/bin/python tools/train.py \
  projects/cfgs/drone/res34_s8_full.py \
  --work-dir /home/hsjeong/workspace/vision-det/GANet/test/002-res34-1cls-1280-150ep \
  --no-validate --gpu-id 0
```
(`source/`에서 실행. `--no-validate`는 GANet 기본 평가가 CULane 공식 C++
평가 도구를 서브프로세스로 부르는데 안 빌드했고 우리 해상도와도 안 맞아서
생략 — 대신 아래 문서의 자동 시각화로 정성 평가.)

체크포인트 저장 간격은 이미 `checkpoint_config = dict(interval=10)`로 설정돼
있었음(변경 불필요). 2026-09-30 16:44:53 두 학습 모두 시작, epoch당 약 75초,
150epoch 총 약 3시간 예상.
