## 1. APT가 무엇인가

논문: *Accelerating Vision Transformers With Adaptive Patch Sizes* (arXiv 2510.18091), 코드 github.com/clamsoup97/apt
(받아 둔 곳 `/home/hsjeong/tmp/apt_ref/src`, 커밋 5cb46df 2025-11-20).

**새로운 어텐션이 아니라 "토큰을 만드는 방식(patch tokenizer)"** 이다. 어텐션 자체는 평범한 self-attention 그대로.

| # | 구성 요소 | APT 코드 | 하는 일 |
|---|---|---|---|
| ① | 패치 크기 결정 | `entropy_utils.py:28`, `:174` | 원본 픽셀(흑백) 엔트로피가 문턱값보다 낮은(단순한) 영역은 큰 패치로. 학습 안 되는 규칙 |
| ② | 큰 패치 임베딩 | `patch_embed.py:300~345` (`TokenizedZeroConvPatchAttn`) | E(줄인 패치) + ZeroMLP(Conv2d 2×2(E(작은 조각들))) + 위치 인코딩(큰 격자로 다시 맞춘 것) |
| ③ | 가변 길이 토큰 | `patch_tokenizer.py:255`, `transformer.py:98` | 이미지마다 토큰 수가 달라 `flash_attn_varlen_func`로 묶어 계산 |
| ④ | Transformer 본체 | `transformer.py` | 그대로 |
| ⑤ | dense task 되돌리기 | 논문 3.3절 (코드 없음) | 큰 패치 토큰을 원래 칸들에 **그대로 반복**해서 격자 특징맵을 만듦 |

> **초급자 설명:** 하늘·빈 도로처럼 단순한 곳은 4칸을 1칸으로 합쳐서 "짐(토큰)"을 줄이는 방법입니다. 목적은 **속도**입니다.
> ②의 ZeroMLP는 0으로 시작하는 층이라, 학습 초기에는 "큰 패치를 그냥 줄인 것"과 똑같이 동작합니다.

## 2. GANet C5에 맞춘 방식 (B 방식)

C5 한 칸 = 입력 32×32 픽셀을 **기본 패치**, 2×2 칸(64×64 픽셀)을 **큰 패치**로 본다. C5 격자 23×40=920칸,
큰 패치 격자 12×20 (23이 홀수라 마지막 줄은 다 안 채워져 → APT 규칙대로 엔트로피를 1e6으로 두어 절대 안 합침).

| APT 구성 | GANet에서 |
|---|---|
| ① 엔트로피 | 입력 이미지(Normalize 되돌린 RGB → 흑백, 512구간 히스토그램)의 64×64 영역 엔트로피 < τ 이면 합침. APT 함수와 같은 계산을 배치로(`scatter_add`) |
| ② E(패치 임베딩) | SA/DA 버전: `pre_conv`(3×3, 512→64)를 E로 봄. 큰 패치 = `pre_conv(2×2 평균한 입력)` + ZeroMLP(Conv2×2(`pre_conv(입력)`의 4칸)). SA 제거 버전: E 없음(C5 그대로), 큰 패치 = 2×2 평균 + ZeroMLP(Conv2×2(4칸)) |
| ② 위치 인코딩 | 기존 sine 위치 인코딩을 2×2 평균해 큰 격자용으로 (APT는 `resample_abs_pos_embed`) |
| ③ 가변 길이 | flash-attn 없음(torch 1.8, cu101) → 작은 칸 920 + 큰 패치 240 을 다 계산하되, **토큰이 아닌 것은 key에서 가림**. 실제 토큰만 모아 계산한 것과 결과가 같음(5절 검증) |
| ④ attention | SA: 기존 `AttentionLayer`의 q/k/v 그대로. DA: query = 토큰(기준점 = 토큰 중심, 큰 패치는 2×2 가운데), value = ⑤로 펼친 격자 |
| ⑤ 되돌리기 | 큰 패치 토큰(과 그 출력)을 4칸에 그대로 반복 → `gamma·out + x` → `final_conv` → FPN |

SA 레이어가 2층이고 그 사이에 3×3 conv가 있어 격자가 필요하므로, **층마다** 같은 병합 자리(mask)로 토큰을 다시 만든다.

> **초급자 설명:** "SA 제거 버전"에는 어텐션이 없어서 줄인 토큰을 쓰는 곳이 없습니다. 그래서 실제로 하는 일은
> "단순한 곳의 C5 특징 2×2를 하나로 합친 뒤 다시 4칸에 복사"입니다. APT의 ①②⑤는 지켰지만 APT의 목적(어텐션 계산 줄이기)은 없는 비교 실험입니다.

### 7-2. 해석

1. **SA에는 APT가 도움이 됐다** (+0.011 평균). 범위가 일부 겹쳐서(011 최저 .757 < 006 최고 .766) 확정은 아니다.
   가능한 이유(검증 안 함): SA는 softmax로 920칸 전체에 주의를 나눠 주는데, 단순한 배경 칸을 합치면 배경이 차지하는 몫이 줄어든다.
2. **DA에는 차이 없음**. DA는 칸마다 주변 32곳만 보므로 배경 칸 수가 줄어도 영향이 작다.
3. **SA 제거 버전에는 오히려 손해** (−0.009 평균, 008 최저 .769 > 013 평균 .765). attention이 없으면 병합은
   "C5 일부를 뭉개는 것"뿐이라 정보만 잃는다 — 2절에서 예상한 대로.
4. **SA+APT(.769)도 SA를 그냥 뺀 것(.774)보다 낮다.** "C5 뒤 attention 블록을 개선하는" 시도(DA, APT)가 모두
   "블록을 빼는 것"을 못 넘었다 → 문서 14에서 세운 가설(512→64 conv 블록 자체가 원인)과 맞는 방향.
