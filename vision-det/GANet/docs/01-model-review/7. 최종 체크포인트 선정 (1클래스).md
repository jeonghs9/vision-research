# 최종 체크포인트 선정 (1클래스)

> 2026-10-01. 관련: [5. 자동 시각화 체계와 epoch별 진행 관찰](5.%20자동%20시각화%20체계와%20epoch별%20진행%20관찰.md)
>
> **결론: 150epoch 전체(10epoch 간격)를 163장 val 전체로 정량 평가해서,
> res18은 epoch140, res34는 epoch150을 최종 채택했다(둘 다 F1 0.758로
> 사실상 동률). `models/drone-ganet-res18-1cls-v1.pth`,
> `models/drone-ganet-res34-1cls-v1.pth`로 승격 완료.**

## 1. 왜 정량 평가가 필요했나

문서 5에서 10장짜리 샘플만 눈으로 보면서 "epoch40에 노이즈, 50에 해소,
150에 재발" 식으로 들쭉날쭉한 인상을 받았다. 전체 150epoch(15개 체크포인트)
×2백본을 10장씩 눈으로 다 훑는 건 비효율적이라, **163장 val 전체에 대한
정량 점수**를 먼저 내고 상위 후보만 눈으로 확인하는 방식으로 바꿨다.

## 2. 평가 방법 — `scripts/04-eval/score_checkpoint.py`

CULane 공식 C++ 평가 도구가 없어서(안 빌드함, 우리 해상도도 다름) 직접 만든
**점 거리 기반 매칭**으로 대체:

1. 예측/정답 차선을 각각 y 기준 20px 간격으로 재샘플
2. 모든 예측-정답 쌍의 겹치는 y구간에서 평균 `|x오차|` 계산
3. 거리가 가까운 쌍부터 그리디로 1:1 매칭 (임계값 40px, 원본 3840 기준)
4. `precision = 매칭된 예측 수 / 전체 예측 수`, `recall = 매칭된 정답 수 / 전체 정답 수`

CULane 공식 IoU 기반 지표와 정확히 같지는 않지만(그래서 "벤치마크 수치"라고
부르지 않음), **체크포인트끼리 상대 비교**에는 충분하다. `gt_points_for_show`가
`test_mode=True`에서도 메타데이터에 그대로 남아있다는 걸 확인해서(디버깅 중
발견) 정답 좌표를 쉽게 가져올 수 있었다.

|---:|---:|---:|---:|---:|
| **140** | 0.899 | 0.655 | **0.758** | 6.96 |
| 80 | 0.913 | 0.643 | 0.754 | 6.78 |
| 150 | 0.921 | 0.637 | 0.753 | 6.79 |
| 120 | 0.896 | 0.650 | 0.753 | 7.02 |
| 90 | 0.926 | 0.631 | 0.751 | 6.69 |

**res34** (상위 5개)

| epoch | precision | recall | F1 | 평균오차(px) |
|---:|---:|---:|---:|---:|
| **150** | 0.897 | 0.656 | **0.758** | 6.96 |
| 120 | 0.877 | 0.659 | 0.753 | 6.84 |
| 110 | 0.880 | 0.657 | 0.753 | 6.85 |
| 140 | 0.891 | 0.651 | 0.752 | 6.89 |

전체 15개 체크포인트×2백본 원본 수치는 `/tmp` 스크래치패드에 있었고(세션
한정), 재현하려면 위 스크립트를 다시 돌리면 된다(체크포인트가 `test/`에
그대로 있는 한 언제든 재현 가능).

## 4. 해석

- **res18 epoch140과 res34 epoch150이 F1 0.758로 사실상 동률** — 백본 간
  우열은 거의 없다.
- 두 백본 다 **epoch 80 전후로 수렴**하고 그 이후는 ±0.01~0.02 범위에서
  등락만 한다. 눈으로 봤던 "중간에 노이즈 생겼다 없어졌다" 하는 변동은
  성능 지표상으론 노이즈 수준이지 실제 추세가 아니었다.
- **precision(0.86~0.93)이 recall(0.58~0.66)보다 항상 높다** — 모델이
  "확신 없으면 안 그린다" 쪽으로 보수적이다. 틀린 선을 많이 그리진 않지만
  실제 차선의 1/3가량을 놓친다. 2클래스 작업과 별개로, 나중에 recall을
  올리는 방향(예: kpt_thr 낮추기, 더 많은 학습 데이터)도 검토 대상.

## 5. 최종 채택

눈으로 상위 후보(res18 epoch140, res34 epoch150)를 한 번 더 확인한 뒤 확정.

```
models/drone-ganet-res18-1cls-v1.pth   (= test/001-.../epoch_140.pth)
models/drone-ganet-res34-1cls-v1.pth   (= test/002-.../epoch_150.pth)
```
