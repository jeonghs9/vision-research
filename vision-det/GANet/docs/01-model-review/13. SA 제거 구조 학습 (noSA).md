# SA 제거 구조 학습 (noSA)

> 2026-11-10 ~ 11-11. 관련: [12. P3 제거 구조 학습 (P3del)](12.%20P3%20제거%20구조%20학습%20%28P3del%29.md) ·
> 그림: `output/07-cls2-P3제거특징맵분석/figures/{n}-12 ~ {n}-15`
>
> **결론: SA(C5 attention)를 빼고 다시 학습해도 163장 val F1은 떨어지지 않았고 오히려 조금 올랐다.
> 기존 0.747 → 기존−SA 0.763, P3del 0.766 → P3del−SA 0.780 (위치만 평가). 다만 차이(+0.014~0.016)가
> 같은 모델의 epoch 간 흔들림(±0.01)과 비슷해서, 1회 학습으로는 "SA가 없어도 나빠지지 않는다"까지만 말할 수 있다.
> 체크포인트 채택(`models/` 승격)은 하지 않았다.**

## 1. 왜 하는가

FPN 단계별 히트맵(10·11번 그림)에서 C5+SA 칸이 차선이 아니라 화면 전체의 넓은 영역에 반응했다.
SA가 차선 검출에 실제로 필요한지 보려고 SA 단계만 뺀 구조를 학습했다.

```text
기존:      C3 -> C4 -> C5 -> SA -> (C5+SA)+C4 = P4 -> P4+C3 = P3 -> LFA(P3) -> head   (1/8)
기존−SA:   C3 -> C4 -> C5 ------> C5+C4      = P4 -> P4+C3 = P3 -> LFA(P3) -> head   (1/8)
P3del:     C3 -> C4 -> C5 -> SA -> (C5+SA)+C4 = P4 -> LFA(P4) -> head                (1/16)
P3del−SA:  C3 -> C4 -> C5 ------> C5+C4      = P4 -> LFA(P4) -> head                (1/16)
```

초급자 설명: SA(self-attention)는 가장 깊은 특징(C5, 화면을 1/32로 줄인 것)에서 "멀리 떨어진 칸끼리 정보를 주고받게"
하는 단계입니다. 차선처럼 길게 이어지는 물체에 도움이 된다고 해서 GANet 원 구조에 들어 있습니다. 이번 실험은
이 단계를 빼도 되는지를 봅니다.

**학습 없이는 비교할 수 없는 이유**: SA가 있으면 C5가 512ch → 64ch로 바뀌고, 뒤의 lateral conv도 64ch 입력으로

가중치 모양이 맞지 않는다.

- **원본 입력**: 프레임 2·3은 네 모델의 선 수가 같다. 프레임 1(먼 원근 다리)은 기존만 실선 4줄이고, 나머지 셋은 2줄이다.
  기존−SA도 P3del처럼 왼쪽 가는 실선 2줄을 놓쳤다.
- **BEV 입력**: SA를 빼면 실선이 1줄씩 줄었다(프레임 1 P3del 2→1, 프레임 2 기존 3→1·P3del 3→2, 프레임 3 기존 3→2).
  12번 문서 8절에서 BEV 입력 때 생기던 난간 실선 오검출이 줄어든 경우도 있지만, 프레임 2 P3del−SA는 점선을 하나도
  못 잡았다. 3장뿐이라 방향을 단정할 수는 없다.

## 5. 결과 — FPN 단계별 히트맵 (12·13번 그림)

블록 4개(기존 / 기존−SA / P3del / P3del−SA) × 3줄(활성 크기, 실선 conf 기여도, 점선 conf 기여도), 7칸.
줄별 의미와 계산 방법은 문서 12의 9-2절과 같다. 모든 모델에서 바꿔 끼운 neck.forward의 conf 출력이 원래 forward와
1e-5 이내로 같음을 실행 때 assert로 확인했다.

conf 0.4를 넘는 칸 수(원본 입력, 실선 / 점선):

| 프레임 | 기존 | 기존−SA | P3del | P3del−SA |
|---|---|---|---|---|
| 1 | 294 / 134 | 179 / 133 | 70 / 54 | 52 / 53 |
| 2 | 145 / 455 | 144 / 417 | 48 / 189 | 51 / 172 |
| 3 | 0 / 366 | 0 / 375 | 0 / 162 | 0 / 151 |

세 프레임 모두에서 보인 차이:

| 단계 | SA 있는 모델 (기존, P3del) | SA 없는 모델 (기존−SA, P3del−SA) |
|---|---|---|
| C5 활성 크기 | 차선·도로 쪽에 반응 | 화면 위쪽(하늘·먼 배경)에 크게 반응 |
| C5 conf 기여도 | 넓은 덩어리, 또는 화면을 가로지르는 띠 | **차선 위치에 좁게 몰림** |
| C5+SA conf 기여도 | 넓은 덩어리 (소실점 부근, 도로 아래쪽) | 칸 없음 |
| C4 · P4 · 최종 conf 기여도 | 차선 위 | 차선 위 (SA 있는 모델과 비슷) |

- SA가 있을 때 C5에서 넓게 퍼지던 기여도는 SA가 C5 정보를 화면 전체에 섞어서 생긴 것으로 보인다.
  SA를 빼면 C5도 C4처럼 차선 자리를 직접 보고 쓴다.
- SA 없는 모델의 C5 **활성 크기**는 하늘 쪽이 가장 크지만, **기여도**는 차선 위에 있다. 반응이 크다고 해서 conf
  예측에 쓰이는 것은 아니다(문서 12의 9-2절과 같은 이야기).

초급자 설명: "활성 크기"는 그 층이 어디에서 강하게 반응했는지, "기여도"는 최종 실선/점선 점수를 만들 때 그 층의
어느 위치를 실제로 썼는지입니다. SA를 빼니 가장 깊은 층(C5)이 '화면 전체 분위기' 대신 '차선이 있는 자리'를 직접
쓰게 바뀌었고, 점수는 떨어지지 않았습니다.
