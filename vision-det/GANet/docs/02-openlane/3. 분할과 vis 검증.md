## 2. test 100개 segment를 고른 방식

- "깨끗한 것만"이 아니라 **training 전체 분포의 12.5%(100/798)에 가깝게** 무작위 탐색(20만 회, seed 1)으로 뽑음.
  맞춘 항목: 프레임 수, 점선·실선·혼합·연석 차선 수, 어두운 segment 수, 정지 위주 segment 수, 이동 거리, 전체 차선 수, 희귀 클래스(3·4·5·6·9).
- 제약: 희귀 category 3·4·5·6·9는 train에 최소 1 segment가 남게 함.
- 결과: test에 정지 위주 28개 · 어두운 15개 segment 포함. 맞춘 항목은 전체 대비 대부분 11~13%.
- 한계: test의 category 3(3개)·5(3개)·9(7개)는 수가 적어 **클래스별 평가는 의미가 약하고**, 실선/점선 묶음 기준 평가가 주가 된다.
